# /refactor — Plan a Refactor

**Usage:** `/refactor <target> <goal>`

**Example:** `/refactor UserService extract authentication logic`

**Output:**
- Current structure analysis
- Proposed changes
- Step-by-step refactoring plan
- Test verification strategy
